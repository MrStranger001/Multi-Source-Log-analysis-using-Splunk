# SPL Queries Used

## View All Events 

```spl
index=test
```

Used to verify that all log sources were successfully ingested into Splunk.

---

## Events by Sourcetype

```spl
index=test
| stats count by sourcetype
```

Used to compare the number of events generated by each log source.

---

## Timeline by Source

```spl
index=test
| timechart count by sourcetype
```

Used to visualize event activity over time across different sources.

---

## Failed Password Attempts

```spl
index=test sourcetype=linux_secure "Failed password"
```

Used to identify authentication failures in Linux security logs.

---

## Failed Password Attempts by IP Address

```spl
index=test sourcetype=linux_secure "Failed password"
| stats count by clientip
| sort - count
```

Used to identify source IP addresses generating failed login attempts.

---

## Failed Password Attempts by User

```spl
index=test source=linux_secure "Failed password"
| stats count by user
| sort - count
```

Used to determine which user accounts were targeted during authentication failures.

---

## Top Client IP Addresses

```spl
index=test sourcetype=access_combined_wcookie
| stats count by clientip
| sort - count
```

Used to identify the most active client IP addresses accessing the web application.

---

## HTTP Status Code Analysis

```spl
index=test sourcetype=access_combined_wcookie
| stats count by status
```

Used to analyze HTTP response codes and understand web traffic behavior.

---

## Database Activity Analysis

```spl
index=test sourcetype=database
| stats count by host
```

Used to review database-related event activity.

---

## Top Hosts Across All Sources

```spl
index=test
| stats count by host
| sort - count
```

Used to identify hosts generating the highest number of events.

---

## Event Distribution Dashboard Query

```spl
index=test
| stats count by sourcetype
```

Used as a dashboard panel to visualize event distribution across log sources.
